# Contributing to Ouroboros

Clarified: November 20, 2026.

## Current status

This repository is a historical technical disclosure containing documentation and an early scheduler excerpt. It is not the active implementation repository.

## Contribution policy

- External code contributions are not accepted at this stage.
- Feedback, corrections and discussion are welcome via Issues.
- No future publication or contribution program is promised.
